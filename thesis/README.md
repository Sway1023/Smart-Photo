# 论文材料目录

本目录用于整理《基于Node+Svelte的私有化共享相册平台》毕业设计论文初稿所需的结构化材料。

当前包含以下文件：

- `论文初稿正文.md`
  提供一份可直接继续增删修改的论文初稿正文，章节结构、模块顺序和图表插入位置已经整理完成。
- `export-thesis-docx.ps1`
  使用 Word COM 自动将 Markdown 正文转换为带封面、摘要、目录和正文样式的 `.docx` 初稿。
- `论文初稿骨架.md`
  说明论文各章节的推荐写法、路由驱动的模块划分、与项目代码的对应关系，以及插图预留位置。
- `图表素材.md`
  提供论文所需图表的 Mermaid 源码、图号建议、图下注释和 draw.io/Visio 转绘说明。
- `测试用例表.md`
  提供第 5 章可直接整理进论文的测试用例表与测试结论写作骨架。

使用建议：

1. 先以 `论文初稿正文.md` 作为论文初稿主文档。
2. 再结合 `论文初稿骨架.md` 做章节增删和模块口径校正。
3. 从 `图表素材.md` 中挑选图表插入第 2 章和第 3 章。
4. 使用 `export-thesis-docx.ps1` 导出带封面、摘要和目录的 Word 初稿。
5. 最后将系统运行截图插入第 4 章对应模块位置，并结合 `测试用例表.md` 完成第 5 章。
